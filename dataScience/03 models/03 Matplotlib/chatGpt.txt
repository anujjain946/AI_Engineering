# 2. Basic Line Plot

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 15, 30, 25]

plt.plot(x, y)
plt.show()
```

Important functions:

```python
plt.plot()
plt.show()
plt.title()
plt.xlabel()
plt.ylabel()
```

---

# 3. Customize Line Plot

```python
plt.plot(
    x,
    y,
    marker="o",
    linestyle="--",
    linewidth=2,
    label="Sales"
)

plt.title("Monthly Sales")
plt.xlabel("Month")
plt.ylabel("Sales")

plt.legend()
plt.grid()

plt.show()
```

Learn:

* `color`
* `marker`
* `linestyle`
* `linewidth`
* `markersize`
* `alpha`
* `label`
* `legend`
* `grid`

# 5. Bar Chart

Used for **categorical data**.

```python
products = ["Laptop", "Mobile", "Tablet"]
sales = [50, 80, 40]

plt.bar(products, sales)

plt.title("Product Sales")
plt.xlabel("Product")
plt.ylabel("Sales")

plt.show()
```

Important:

```python
plt.bar()
plt.barh()
```

Horizontal bar:

```python
plt.barh(products, sales)
```

---

# 6. Multiple Bar Charts

```python
import numpy as np
import matplotlib.pyplot as plt

products = ["Laptop", "Mobile", "Tablet"]

sales_2024 = [50, 80, 40]
sales_2025 = [60, 90, 55]

x = np.arange(len(products))
width = 0.35

plt.bar(x - width/2, sales_2024, width, label="2024")
plt.bar(x + width/2, sales_2025, width, label="2025")

plt.xticks(x, products)
plt.legend()

plt.show()
```

# 7. Pie Chart

# 8. Histogram

Very important for **Data Science and ML**.

Used to understand **distribution of numerical data**.

```python
import numpy as np
import matplotlib.pyplot as plt

data = np.random.normal(50, 10, 1000)

plt.hist(data, bins=30)

plt.title("Age Distribution")
plt.xlabel("Age")
plt.ylabel("Frequency")

plt.show()
```

Learn:

* bins
* density
* cumulative
* alpha

---

# 9. Scatter Plot

Very important for **Machine Learning**.

Used to understand relationships between two variables.

```python
hours = [1, 2, 3, 4, 5, 6]
marks = [40, 45, 50, 60, 70, 80]

plt.scatter(hours, marks)

plt.xlabel("Study Hours")

```

Useful for:

# 10. Subplots

You can create multiple plots in one figure.

```python
fig, ax = plt.subplots(2, 2)

ax[0, 0].plot(x, y)
ax[0, 1].bar(products, sales)
ax[1, 0].scatter(hours, marks)
ax[1, 1].hist(data)

plt.show()
```

Understand:

```text
Figure
 ├── Axes
 ├── Axes
 ├── Axes
 └── Axes
```

This is an **important interview topic**.

---

# 11. Figure and Axes

Instead of only using `plt`, learn the **Object-Oriented API**.

```python
fig, ax = plt.subplots()

ax.plot(x, y)

ax.set_title("Sales")
ax.set_xlabel("Month")
ax.set_ylabel("Revenue")

plt.show()
```

Recommended for professional projects.

# 15. Multiple Y-Axis

Sometimes two variables have different scales.

```python
fig, ax1 = plt.subplots()

ax1.plot(x, sales)
ax1.set_ylabel("Sales")

ax2 = ax1.twinx()

ax2.plot(x, profit)
ax2.set_ylabel("Profit")

plt.show()
```

Important interview concept:

**`twinx()` creates a second y-axis sharing the same x-axis.**

# 23. Heatmap with Matplotlib

Matplotlib doesn't have Seaborn's dedicated `heatmap()` function, but you can use `imshow()`.

```python
data = [
    [10, 20, 30],
    [20, 40, 60],
    [30, 60, 90]
]

plt.imshow(data)

plt.colorbar()

plt.show()
```

For Data Science, you'll commonly see heatmaps through Seaborn.

# 24. ML Visualization

Matplotlib becomes especially important in Machine Learning.

### Training Loss

```python
plt.plot(history.history["loss"])
plt.plot(history.history["val_loss"])

plt.xlabel("Epoch")
plt.ylabel("Loss")

plt.legend(["Training", "Validation"])

plt.show()
```

### Accuracy

```python
plt.plot(history.history["accuracy"])
plt.plot(history.history["val_accuracy"])

plt.xlabel("Epoch")
plt.ylabel("Accuracy")

plt.legend(["Training", "Validation"])

plt.show()
```

You can identify:

```text
Overfitting
Underfitting
Training performance
Validation performance
```

# 25. Regression Visualization

```python
plt.scatter(y_test, predictions)

plt.xlabel("Actual")
plt.ylabel("Predicted")

plt.title("Actual vs Predicted")

plt.show()
```

Ideal regression model:

```text
Actual ≈ Predicted
```

You can also add a reference line:

```python
plt.plot(
    [min(y_test), max(y_test)],
    [min(y_test), max(y_test)]
)
```

# 26. Confusion Matrix Visualization

```python
from sklearn.metrics import confusion_matrix
import matplotlib.pyplot as plt

cm = confusion_matrix(y_test, y_pred)

plt.imshow(cm)

plt.colorbar()

plt.xlabel("Predicted")
plt.ylabel("Actual")

plt.title("Confusion Matrix")

plt.show()
```

For production-quality ML reports, `ConfusionMatrixDisplay` from scikit-learn is often more convenient.

# 29. Professional Plot Structure

For professional projects, prefer:

```python
fig, ax = plt.subplots(figsize=(10, 6))

ax.plot(
    x,
    y,
    marker="o",
    label="Sales"
)

ax.set_title("Monthly Sales")
ax.set_xlabel("Month")
ax.set_ylabel("Revenue")

ax.legend()
ax.grid(True)

plt.tight_layout()
plt.show()
```

This is better than putting everything directly through `plt` when your visualization becomes complex.

## 🎯 Best Learning Order for You

Since you're preparing for **Data Science / ML / AI interviews**, don't try to memorize every Matplotlib function.

Follow this order:

**Level 1 — Must Know**

`plot → scatter → bar → histogram → pie → boxplot`

⬇️

**Level 2 — Data Science**

`subplots → figure/axes → ticks → labels → legend → grid → annotations`

⬇️

**Level 3 — EDA**

`distribution → outliers → correlation → categorical comparison → time series`

⬇️

**Level 4 — ML**

`loss curve → accuracy curve → confusion matrix → ROC → actual vs predicted → residual plot`

⬇️

**Level 5 — Advanced**

`OO API → GridSpec → colorbar → colormap → tick formatter → multiple axes → custom artists → animation`

**For interviews, the most important concepts are:** `Figure vs Axes`, `plt vs OO API`, `subplots`, histogram vs bar chart, scatter plot, box plot/outliers, customization, saving figures, and ML training/validation plots.
