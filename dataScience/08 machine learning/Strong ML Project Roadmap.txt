# 🧠 How to Learn Each Project Strongly

Don't simply copy a YouTube project.

For **every project**, follow these 10 steps:

### 1️⃣ Understand the Problem

Ask:

> What problem am I solving?

> Is it regression, classification, clustering, anomaly detection, or forecasting?

---

### 2️⃣ Understand the Dataset

Know **every column**.

For example:

```text
Age
Income
Education
MaritalStatus
PreviousPurchase
Purchase
```

You should be able to explain what every feature means.

---

### 3️⃣ Perform EDA

```text
Shape
 ↓
Info
 ↓
Missing Values
 ↓
Duplicates
 ↓
Statistics
 ↓
Distribution
 ↓
Outliers
 ↓
Correlation
 ↓
Feature vs Target
```

---

### 4️⃣ Build a Baseline Model

Don't immediately use XGBoost.

Start simple:

```text
Logistic Regression
```

Then compare:

```text
Decision Tree
Random Forest
XGBoost
```

---

### 5️⃣ Evaluate Properly

For classification:

```text
Accuracy
Precision
Recall
F1
ROC-AUC
Confusion Matrix
```

For regression:

```text
MAE
MSE
RMSE
R²
Adjusted R²
```

---

### 6️⃣ Improve the Model

Try:

```text
Feature Engineering
      ↓
Scaling
      ↓
Feature Selection
      ↓
Cross Validation
      ↓
Hyperparameter Tuning
      ↓
Model Comparison
```

---

### 7️⃣ Explain WHY

This is extremely important for interviews.

Don't just say:

> Random Forest gave 92% accuracy.

Be able to say:

> Random Forest performed better because it captures nonlinear relationships and reduces the variance associated with a single decision tree through ensemble learning.

---

### 8️⃣ Save the Model

```python
joblib.dump(model, "model.pkl")
```

Also save:

```text
Scaler
Encoder
Feature Columns
Model
```

---

### 9️⃣ Create API

Example:

```text
POST /predict
```

Input:

```json
{
    "age": 32,
    "income": 50000,
    "previous_purchase": 3
}
```

Output:

```json
{
    "prediction": 1,
    "probability": 0.87
}
```
